# Test

Test plan, test cases and test reports (PA4–PA5).

## Viết ca kiểm thử PA4

1. Chép [TEMPLATE-Fxx.md](TEMPLATE-Fxx.md) thành `Fxx.md` của tính năng mình, ví dụ `F05.md`.
2. Điền phần đầu, rồi viết **Danh sách ca**. Mã ca dạng `TC-Fxx-NN`, cột FR ghi `FR-Fxx-NN`. Giữ nguyên tiêu đề mục và tiêu đề cột để tạo được ma trận `FR → TC`.
3. Viết **Đặc tả ca chi tiết** cho số ca được giao trong [Kế hoạch PA4 và PA5](../management/PA4-phan-cong.md).
4. Dùng tên theo [GLOSSARY.md](../../GLOSSARY.md) và mã fixture seed trong [contracts.md](../design/contracts.md).
5. Xóa các dòng ví dụ F01 khỏi file của mình (trừ khi đó chính là `F01.md`).
